# Dota2 Plus Live HUD — نسخه دسکتاپ (Electron)

این پوشه، نسخه‌ی تبدیل‌شده به اپلیکیشن ویندوزی پروژه‌ی وبی شماست.

## چه چیزهایی تغییر کرد؟

- **`server/gsi-server.js`** — نسخه‌ی ساده‌شده‌ی `server.js` اصلی: سیستم چندکاربره‌ی `userKey` (که برای دیپلوی روی VPS بود) حذف شد، چون روی دسکتاپ فقط یک کاربر (خودتون) وجود داره. سرور فقط روی `127.0.0.1` گوش می‌ده، نه `0.0.0.0` — یعنی از بیرون سیستم شما قابل‌دسترسی نیست.
- **`server/gsi-config-writer.js`** — مسیر نصب Dota 2 رو خودکار پیدا می‌کنه (از رجیستری ویندوز + فایل `libraryfolders.vdf` استیم، برای وقتی که بازی روی درایو دیگه‌ای نصب شده) و فایل `gamestate_integration_dota2plus.cfg` رو خودش می‌سازه — دیگه نیازی نیست دستی کپی کنید.
- **`main.js`** — پروسه‌ی اصلی Electron: سرور رو داخل خود اپ اجرا می‌کنه، یه پنجره باز می‌کنه که HUD رو نشون می‌ده، و یه آیکون توی System Tray می‌ذاره (با گزینه‌ی «پیکربندی مجدد GSI» برای وقتی که تشخیص خودکار جواب نداد).
- **`public/`** — دقیقاً همون فایل‌های `index.html` / `app.js` / `style.css` / `assets` قبلی، بدون تغییر (چون `USER_KEY` توی `app.js` از قبل مقدار پیش‌فرض `'default'` داشت، لازم نبود دست بخوره).

## چطور اجرا/بیلدش کنم؟

روی یه سیستم **ویندوزی** با Node.js نصب‌شده (نسخه ۱۸ به بالا):

```bash
npm install
npm start          # برای تست، بدون ساخت exe
```

برای گرفتن فایل نصبی (`.exe`):

```bash
npm run dist
```

خروجی داخل پوشه‌ی `dist/` قرار می‌گیره: یه نصب‌کننده‌ی NSIS و یه نسخه‌ی portable.

> توجه: چون این محیط توسعه دسترسی به اینترنت و ویندوز نداره، خودم نتونستم `npm install` و بیلد نهایی رو اجرا کنم — باید این دو دستور رو خودتون روی ویندوز اجرا کنید.

## نکات

- تشخیص خودکار مسیر Dota 2 فقط روی ویندوز کار می‌کنه (از `reg query` استفاده می‌کنه). اگه بازی رو جای غیرمعمولی نصب کرده باشید یا تشخیص خودکار جواب نده، از منوی Tray گزینه‌ی «پیکربندی مجدد GSI…» رو بزنید و پوشه‌ی `.../dota 2 beta/game/dota/cfg` رو دستی انتخاب کنید.
- پورت داخلی اپ `33771` هست (فقط لوکال، قابل تغییر در `main.js`).
- آیکون اپ (`build/icon.ico`) از روی آیکون خود پروژه ساخته شده؛ اگه دوست دارید عوضش کنید، کافیه فایل ico دلخواه رو جای همون بذارید.
- بستن پنجره (X) اپ رو نمی‌بنده، فقط مخفیش می‌کنه (سرور تو تری فعال می‌مونه) — خروج واقعی از منوی تری انجام می‌شه.
